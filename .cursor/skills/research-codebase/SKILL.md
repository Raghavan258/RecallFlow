# Research a Codebase
1. Identify project structure, entry points, and dependency manifests.
2. Trace the relevant feature through UI, APIs, services, data, and integrations.
3. Read actual implementations and tests instead of inferring from names.
4. Identify contracts, dependencies, configuration, and error paths.
5. Separate verified findings from assumptions.
6. Report file paths, hypotheses, risks, and next steps.
7. Do not modify files during investigation.\n
